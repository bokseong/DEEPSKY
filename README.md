# DEEP SKY

복성고등학교 천문·항공우주 동아리 DEEP SKY의 공식 웹사이트입니다.

- 동아리 소개, 활동 사진, 자료실 및 동아리 게시판
- 관측 일정, 공지사항과 업데이트 기록
- 순천 현재 기상, 야간 관측 조건 및 상세 관측 도구
- Firebase Authentication 로그인과 자체 서버 JSON 데이터 저장

## 확인

```powershell
npm test
```
