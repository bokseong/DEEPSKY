Project Overview

DEEP SKY는 밤하늘을 직접 관측하고, 관측 데이터를 과학적으로 해석하며 우주를 탐구하는 복성고등학교 천문·항공우주 동아리입니다.

망원경 운용과 천체 관측부터 외계행성 데이터 분석, 항공우주 프로젝트까지 다양한 활동을 함께 수행합니다. 관측 과정과 탐구 결과를 기록하고 공유하며, 질문을 실제 관측과 데이터로 확인하는 경험을 쌓아갑니다.
