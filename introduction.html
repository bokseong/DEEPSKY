Project Overview

DEEP SKY는 밤하늘을 직접 관측하고, 관측 데이터를 과학적으로 해석하며 우주를 탐구하는 복성고등학교 천문·항공우주 동아리입니다. 교과서에서 배운 천문학과 물리학의 개념을 실제 관측과 데이터에 연결하면서, 우주에 관한 질문을 스스로 만들고 답을 찾아가는 활동을 이어가고 있습니다.

주요 활동은 망원경 운용과 천체 관측, 외계행성 관측 데이터 분석, 항공우주 관련 프로젝트입니다. 관측 대상을 이해하고 필요한 자료를 살펴본 뒤, 직접 얻은 관측 결과와 다양한 데이터를 정리하고 분석합니다. 단순히 천체를 보는 데서 그치지 않고 관측 결과가 무엇을 의미하는지 생각하며 과학적인 근거를 바탕으로 해석하는 과정을 중요하게 다룹니다.

관측과 분석 과정에서 생긴 오류나 예상과 다른 결과도 중요한 탐구 자료로 활용합니다. 어떤 조건이 결과에 영향을 주었는지 확인하고, 필요한 경우 관측 방법과 데이터 처리 과정을 다시 검토합니다. 이러한 과정을 통해 정확한 기록, 객관적인 판단과 반복 검증이 과학 탐구에서 왜 필요한지 경험합니다.

DEEP SKY는 활동 과정과 탐구 결과를 체계적으로 기록하고 구성원들과 공유합니다. 각자의 관찰과 생각을 나누고 함께 문제를 해결하면서 천문학과 항공우주 분야에 대한 이해를 넓혀갑니다. 앞으로도 직접 관측하고 분석하는 경험을 바탕으로, 밤하늘과 우주를 더 깊이 탐구해 나가고자 합니다.
